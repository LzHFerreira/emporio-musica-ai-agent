Empório da Música — AI customer service that can't make up prices

Customers ask about instruments, stock, orders and promotions. The model writes the conversation, but prices, stock and order status come from the store's data and are rendered by the application. Customer identity and order ownership are enforced in code, not left to the model.

Design

How it keeps answers honest

The model proposes. The application checks, renders and decides.

Facts come from the store's data

The model cites catalog or order references. The application renders availability and price lines from those rows. A draft that types its own price or stock while catalog evidence is present is rejected.

emporio/agent_render.py:51-61

JSON-only replies, bounded retries

The model must finish with a valid JSON object. A rejected draft goes back for another try. After four model steps, the app sends a fixed safe reply.

emporio/agent_protocol.py:77-89 emporio/agent_turn.py:68-80

Identity and orders enforced in code

The customer is found from the sender's phone number. An order is returned only when it belongs to that customer. The model cannot change either one by what it says.

emporio/orders_access.py:73-112

Attacks and off-topic requests refused

The recording includes a coding request, a film question, an "ignore your instructions" demand and an admin claim. Across the three attack messages, no stock count, phone number or order detail was disclosed. The other-customer order was denied and handed to a human.

Live model

Try it yourself with a live model

These steps assume a fresh clone. Run them in a terminal from the project folder. For Windows commands, see README step 1 to 3.

1. Install uv

uv installs Python and the project's libraries.

curl -LsSf https://astral.sh/uv/install.sh | sh

Open a new terminal afterwards so uv is found.

2. Get the code

git clone https://github.com/LzHFerreira/emporio-musica-ai-agent.git
cd emporio-musica-ai-agent

3. Create your settings file

cp .env.example .env

4. Get a free Cloudflare account and token

  1. Create a free account at dash.cloudflare.com.
  2. Open AI → Workers AI and choose Use REST API. Copy your Account ID.
  3. Click Create a Workers AI API Token and copy the token.
  4. Open .env in a text editor and set:
CLOUDFLARE_ACCOUNT_ID=paste-your-account-id
CLOUDFLARE_API_TOKEN=paste-your-token

The app also accepts CLOUDFLARE_API_KEY, which takes precedence if set. CLOUDFLARE_MODEL is optional and defaults to @cf/zai-org/glm-4.7-flash. Keep .env private: it holds your token.

5. Install, create the database and load the store data

uv sync --locked
uv run --env-file .env python manage.py migrate
uv run --env-file .env python manage.py load_sources --source-dir data

6. Talk to the assistant

Interactive chat. Type your questions in Portuguese and /quit to leave:

uv run --env-file .env python manage.py interact_chat

One message, then exit:

uv run --env-file .env python manage.py interact_chat --message "Quanto custa o Takamine GD20?"

Act as synthetic customer 1 (sender 5567998123456) so order lookups are scoped to that customer:

uv run --env-file .env python manage.py interact_chat --sender 5567998123456 --message "Quanto custa o Takamine GD20?"

Or run fully local with Ollama

In .env, set:

MODEL_PROVIDER=ollama
OLLAMA_BASE_URL=http://localhost:11434/v1
OLLAMA_MODEL=qwen3:4b

Install Ollama, download the model named in OLLAMA_MODEL, keep it running, then use the same interact_chat commands. OLLAMA_TIMEOUT_SECONDS defaults to 180. On slow hardware, raise TURN_DEADLINE_SECONDS (default 60).

What to expect

  • Replies took 9.7 to 68.8 seconds in the recorded run. Times vary with your network and the model host.
  • A live model may answer differently on each run. The recorded outcomes are one snapshot, not a guarantee.
  • Safe fallbacks happen. The generic reply "Não consegui concluir sua consulta agora..." is expected when the app cannot verify an answer.
  • No account or credentials yet? After steps 2 to 5, run the scripted demo. It uses the store data with a scripted model, not a live one:
uv run --env-file .env python manage.py demo_chat

Seeing "accepted_count": 5 means the install works.

Honest limits

What it does not do yet

  • The live evidence is small: 9 turns in 5 conversations at one commit. It is not an independent quality evaluation.
  • A turn can run past the 60 s deadline and get no reply. This happened once in the recording (68.8 s).
  • A PIX follow-up currently falls back to the safe reply in the recording.
  • Output checks catch known kinds of error, not general falsehood. An accepted reply is not proof of correctness.
  • Policy retrieval is lexical and hand-tuned. Unseen phrasings can miss, and policy answers are phrase-checked.
  • Order status is shown verbatim in English (for example delivered). Handoff state does not establish a live human transfer.
  • Messages are not sent to WhatsApp yet. Replies go to a local Meta mock, so live delivery is not established.
